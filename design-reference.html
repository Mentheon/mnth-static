Reminiscence therapy is widely used in dementia care, but is constrained by the availability of personalised material and the cognitive demands of conventional media. Animation idioms · anime.js v4§ 15

Common patterns used across ConceptView, StrandDetail, and the HomeMashup scenes. Easings drop the ease prefix in v4 ('easeOutQuad' → 'outQuad').

Stagger entrance

Fade-in a sequence of elements with a 60–110 ms stagger.

animate(els, { opacity: [0, 1], translateY: [16, 0], duration: 460, delay: stagger(110), ease: 'outQuad', })

Stroke draw-on

For SVG paths — set dash to length, animate offset to 0.

const len = path.getTotalLength() path.style.strokeDasharray = String(len) path.style.strokeDashoffset = String(len) animate(path, { strokeDashoffset: [len, 0], duration: 1100, ease: 'inOutQuad', })

Counter rollover

Tween a dummy object's value, read live in onUpdate.

animate({ v: 0 }, { v: 12847, duration: 1500, ease: 'outQuart', onUpdate: (a) => { const v = Math.round(a.targets[0].v) el.textContent = v.toLocaleString() }, })

Looping pulse

Heartbeat / breath effect on a single element.

animate(dot, { r: [9, 16], opacity: [0.18, 0], duration: 1600, ease: 'outQuad', loop: true, })

Two-layer transform trick

Anime CSS transforms override SVG transform attributes. Wrap placement in an outer <g>, animate the inner one.

const placement = svgGroup({ transform: 'translate(x y)' }) const animTarget = svgGroup() placement.appendChild(animTarget) animate(animTarget, { scale: [0.4, 1] })

Cleanup discipline

Always pause animations AND clear DOM in effect cleanup — StrictMode dev re-runs the effect, stacking duplicates otherwise.

return () => { timers.forEach(clearTimeout) animations.forEach(a => a.pause()) while (svg.firstChild) svg.removeChild(svg.firstChild) }
